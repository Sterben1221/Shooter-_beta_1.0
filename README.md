# DEAD LOCK PROTOCOL - beta 4 (PS2)

Shooter en primera persona (raycaster) para PlayStation 2.

## Novedades beta 4
- Pantalla de titulo con menu: INICIAR JUEGO (facil / medio / dificil), OPCIONES (sensibilidad y sonido), CONTROLES (cambiar botones), SALIR.
- START durante la partida = pausa (continuar, opciones, controles, menu principal).
- Puertas animadas (4 cuadros), cajas de municion por tipo, botiquin, chaleco.
- Solo puedes llevar 3 armas: con L2 sueltas la actual o la cambias por la que tengas debajo.

## Controles por defecto
Stick izq. / D-pad: mover y girar | Stick der.: girar | Cuadrado / Circulo: de lado
X o R2: disparar | Triangulo: recargar | L1 / R1: cambiar arma | L2: soltar / cambiar arma | START: pausa
En los menus: D-pad o stick para moverse, X acepta, O vuelve.

## Compilar
Subir los archivos a GitHub (Upload files); Actions genera fps.elf (artefacto fps-ps2).
